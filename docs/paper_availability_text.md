# Draft Paper Availability Text

The SPHEREx feature-map pipeline used in this work, SPIRAL
(SPHEREx Pipeline for Infrared Recombination and Aromatic-Line mapping), is
publicly available at `https://github.com/cli-tsinghua/SPIRAL`.  The repository
contains the code, configuration templates, and documentation needed to
reproduce the LMC and SMC maps from public SPHEREx L2 products.  The derived
map products are not distributed with the code release because of their data
volume, but are available from the author upon reasonable request.

Users of SPIRAL should cite this paper and the versioned software release.  The
software citation metadata will be updated with the paper arXiv identifier and
release DOI before public release.
