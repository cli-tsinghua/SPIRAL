# Paper Availability and Citation Text

The SPHEREx feature-map pipeline used in this work, SPIRAL
(SPHEREx Pipeline for Infrared Recombination and Aromatic-Line mapping), is
publicly available at `https://github.com/cli-tsinghua/SPIRAL`.  The repository
contains the code, configuration templates, and documentation needed to
reproduce the LMC and SMC maps from public SPHEREx L2 products.  The derived
map products are not distributed with the code release because of their data
volume, but are available from the author upon reasonable request.

The associated paper, "SPHEREx 3.3 Micron Aromatic Emission in the Magellanic
Clouds: Separating Dust Column, Excitation, and Environmental Suppression," is
available as [arXiv:2609.20295](https://arxiv.org/abs/2609.20295) and has been
accepted for publication in *The Astrophysical Journal*.

Users of SPIRAL should cite both the paper and the versioned SPIRAL v0.1.0
software archive, available from Zenodo at
[doi:10.5281/zenodo.22103715](https://doi.org/10.5281/zenodo.22103715).
